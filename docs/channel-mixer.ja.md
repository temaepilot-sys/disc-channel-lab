# チャンネルミキサー

[English](channel-mixer.md)

対応するマルチチャンネル音源を選び、**ミキサーを開く**を押します。対応音源で初めて開くと「ミキサーを再生に適用」がオンになります。別窓を閉じても再生と設定は維持します。対応範囲は3～8chの28配置です。モノラル・ステレオ音源はメイン画面の再生操作を使います。

## レベルとピーク表示

- チャンネルごとに入力・調整後L/Rピーク、縦型フェーダー、数値入力、Mute、左右パンを配置。メイン画面の入力ピークと音量操作も残しています。
- 各チャンネルは0～100%。フェーダーは聴感カーブ、数値は振幅の比率です。100%では追加の全体減衰を行いません。初期値はFront 100%、Center・Surround 約70.71%、LFE 0%です。
- パンは等電力カーブです。左系はL、右系はR、中央系とLFEはCenterが初期値です。FLをL端、FRをR端にして100%にするとInputとその側のPostが一致します。Centerでは左右へ分配するため、各側が約3 dB下がります。
- Masterはメイン画面の音量と共通で0～200%。「デフォルトに戻す」は各チャンネルのレベル・パン・Muteを初期化し、Masterは維持します。
- Inputはミックス前、Post L/Rは各チャンネルの調整後・Master前、Output L/Rは全チャンネルの合成後・Master適用後・クリップ前です。同じ20msのPCM区間を再生時計に合わせて表示します。赤色は0 dBFS以上です。
- 「ミキサーを再生に適用」をオフにすると標準ミックスで再生します。メイン画面で個別チャンネルを選ぶとソロ試聴になり、有効なミキサーを操作するとステレオ試聴へ戻ります。

## FLAC保存

ミキサー内の**このミックスをFLAC保存**、またはメイン画面の**チャンネルミキサーの設定で2ch FLACを保存**を使います。メイン画面の選択曲・音質・保存先を使用し、保存開始時に再生を停止します。

フェーダー・パン・Muteは試聴と同じ係数を使います。Masterは標準では保存に含めません。必要に応じて「Master音量も保存に適用」を選んでください。設定は保存開始時に固定し、その後の操作で処理中の保存結果は変わりません。

ファイル名には `[Mixer - 名前]` が付き、`MIXER_VARIANT` と `MIXER_SETTINGS` タグにも名前と設定を記録します。既存ファイルは連番で保護します。チャンネル数・周波数・ビット深度・サンプル数を確認してから完成品として配置します。

自動ノーマライズやリミッターはありません。浮動小数点で合成し、整数FLACの範囲を超えた値は飽和させて折り返しを防ぎます。合成レベルが大きすぎる場合の音割れは防ぎません。

## JSONプリセット

**設定を保存…／設定を読み込む…**で、任意のJSONファイルを使えます。ミックス名、チャンネル別のGain・Pan・Mute、Masterの値とカーブ、保存へのMaster適用設定を記録します。ディスク名・曲情報・保存先は含めません。

形式は `DiscChannelLab.MixerPreset`、バージョンは `1`。Gainは0～1、Panは−1（左）～+1（右）、Masterは0～200%です。配列の順序ではなくチャンネルコードで照合するため、同じ構成なら別ディスクでも再利用できます。構成の不一致、値の範囲外、必須項目の欠落、不正な形式、未対応バージョンは、現在の設定を変更せずに拒否します。読み込みが成功すると再生への適用がオンになります。

同じ起動中はディスクや音声を切り替えても共通するチャンネルの設定を維持します。アプリを終了しても再利用する場合はプリセットを保存してください。ディスク情報の保存とは独立しています。

開発用の検証コマンドは[英語版](channel-mixer.md#developer-checks)に掲載しています。
