# オブジェクト音声・ADM ガイド

## 最初に

この機能は、音の位置情報を読み、選んだHRTFでヘッドホン用の左右2chを作る実験的な再生機能です。2ch出力でも、位置情報が失われた通常のダウンミックスとは処理が異なります。

対象は、自作・許諾済みなど、利用権限のある保護されていないデータです。コピー保護解除は行いません。公式のDolby Atmosレンダラー、認証製品、原制作時の音場の完全な再現を意味するものではありません。

## 対応する入力

- 位置情報付きのADM BWF / RF64 / BW64：48 kHz PCMまたはfloat。ObjectsとDirectSpeakersの対応範囲を読みます。
- TrueHD Atmos：外部truehdd 0.6.2が取り出したPCMと位置情報を使います。FFmpegも必要です。公開用にはこれらのツールを同梱しません。
- 通常の2ch・5.1ch・7.1ch：従来のスピーカー配置で再生します。チャンネルPCMだけからAtmosオブジェクトの位置を復元することはできません。
- E-AC-3 JOCのオブジェクト再生、高度なADMの全機能、保護された入力には対応しません。

## 再生する

1. ドライブ、Open folder、Open audio filesから音源を開きます。
2. 対応を検出すると、左側のEnable ADM playbackが押せるようになります。検出しただけでは再生方式を変更しません。
3. ボタンを押します。TrueHD Atmosは最初の短い範囲を先読みします。全曲のADM保存完了を待つ必要はありません。ツールが未設定ならtruehdd.exeを選びます。
4. メイン画面で曲を選び、Playを押します。Pause、Previous / Next、時間バーは従来どおりです。
5. ADM sceneから位置を確認します。ヘッドホンのSOFAはHRTF / roomから選びます。反射なしのPure HRTFを比較の出発点にしてください。

## シークと待ち時間

準備済みの範囲へ戻る場合は、キャッシュのPCMと位置情報を使います。未準備の先へ移動すると、その位置までデコーダーを進めます。左側のPrepared表示で準備状況を確認できます。

準備が必要な位置を選ぶと、Prepared（準備済み）の時刻が太字の赤色になり、待ち時間の案内を表示します。Play後は「再生準備中」と指定位置を示し、音が出始めると通常表示へ戻します。一時停止中に選んだ未準備の位置は、Playを押すと準備を進めます。

初回に大きく先へ移動すると待ち時間があります。位置情報やデコーダーの履歴を推測して即座に再生する方式ではありません。先読みは音声処理・UIから離れた処理で行い、再生用のメモリーバッファは上限を設けています。

一時停止中は少量の先読みで止まります。ディスク上のキャッシュ容量は準備した位置まで増えます。特に長時間音源で遠くへシークすると大きくなります。ADM再生を解除するか、アプリを終了すると、この再生セッションの一時キャッシュを解放します。異常終了で残った分はCache controlで削除できます。曲名・アルバム名・SOFA設定は別に保持します。

## 2ch・5.1ch・Objectsを比べる

TrueHD Atmosの随時再生中はCompare source presentationで選びます。

- Objects：デコードされた位置付き音源を、選択したヘッドホン方式（初期はHRTF）でレンダリングします。
- 5.1 presentation：同じビットストリームの5.1chプレゼンテーションを、標準スピーカー位置からそのヘッドホン方式で鳴らします。
- Stereo presentation：同じビットストリームの2chプレゼンテーションをそのまま左右へ出します。HRTFと追加の室内反射は通しません。

曲と再生位置を引き継いで切り替えます。切替には短い再構築中断があります。これらは独立した市販ステレオ版／5.1版を自動的に探す機能ではありません。元のミックス、ダウンミックス係数、レンダリングの違いで音量・音色が変わり得ます。この切替自体に自動ラウドネス一致はありません。音量が大きい方式を高音質と判断せず、同一区間で音量も揃えて比較してください。

## 3Dの見方とSolo

床のアンバー色の矢印と右上のFRONTが音源空間の前方です。図の視点を回しても、音の頭部方向は変更しません。

既定視点はリスナーの背後から正面を見る向きで、左右の音源がリスナー基準の左右に対応します。リスナーの正面側へ回り込むと、見た目の左右が入れ替わるのは自然な視点変化です。Homeで既定の背後視点へ戻ります。ヘッドホンの頭部姿勢は変えません。

左ドラッグ／矢印で回転・俯瞰、右ドラッグで平行移動、ホイールで拡大縮小、Homeで既定位置へ戻します。

各球のラベルは移動・視点変更に追従し、下の一覧の「Label」列と対応します。デコードされた「Object 12」などの番号はそのまま表示し、スピーカーのベッドはチャンネル名を表示します。番号のない一般ADMの音源は一覧順の「#」参照番号になります。無効な時間帯や画面外の球のラベルは非表示になります。

**Clear Solo**の隣にある**Show labels**で、ラベルと引き出し線の表示を切り替えられます。選択はSpatial Labを閉じる際に保存されます。初期設定は表示オンです。

球をクリックするとその音だけをSoloにし、同じ球を再度クリックすると解除します。Shift+クリックまたは一覧のチェックで複数Soloを選べます。Clear Solo／Escで全解除します。

音源オブジェクトは、楽器や歌声がきれいに分かれたスタジオの元トラックとは限りません。空間符号化された複数の音が含まれる場合があります。表示位置は精密な物理音場や、必ずその場所に聴こえることの保証ではありません。

Soloは試聴専用です。Save ADMやFLACの書き出し結果には反映しません。Labを閉じる、比較方式を切り替える、ADMを解除する、音源を変える操作でSoloを解除します。

## 保存する

Save ADMは、全タイトルの音声・位置・曲境界を一つのBW64ファイルに保存します。随時再生とは別の明示操作で、全曲の準備時間と大きな空き容量が必要です。

保存前に、メイン画面でディスク名・タイトル名（アルバム名）・曲名・アーティスト名を編集してください。Save ADMは、その時点の全曲一覧と編集した曲境界をWAV内に埋め込みます。以前作成したADMを再利用する場合も、音声を再変換せずに最新の編集内容を反映します。保存したWAVをOpen audio filesで開けば、別の曲情報ファイルがなくても復元できます。ディスク名とタイトル名は別々に保持し、日付・ジャンル・発売元・説明があれば一緒に保存します。音声サンプルと位置情報は維持し、準備済みの元ADMも変更しません。曲情報にはDiscChannelLab独自の埋め込みメタデータ`dclc`を使うため、他のADMアプリでは標準の番組名だけが表示される場合があります。既存の書き出しファイルは上書きしません。修正後の情報を反映するには、別名で保存してください。

ADM WAVやFLACの書き出しが成功すると、保存先を記載した完了ダイアログを表示します。キャンセル・失敗時には成功通知を出しません。設定・プロファイル・評価記録・診断レポートの手動保存にも完了通知を表示し、設定や曲情報の自動保存では表示しません。

BDタイトルは単一・複数クリップとも、PlayItemごとに外部デコーダーを厳密モードで起動し、クリップ境界を越えた状態の持ち越しを避けます。PCMのチャンネル順と位置・ゲインの時刻を明示的に接続し、次クリップへ誤って補間しません。映像の区間より音声が早く終わる場合は、元ストリームのPTS・長さで音声が存在しない末尾を確認して無音区間を維持します。クリップの外へはみ出した最大1アクセスユニットは指定された終了点で切り、予期しないデコード欠落や長さの不一致はエラーにします。補正の内訳は `.import.json` に記録します。元のディスクと曲情報は変更しません。メタデータの結合とWAV保存はバックグラウンドで処理します。

正常なMPEG-TS音声でも、ストリーム全体の長さを取得できない場合があります。その場合は、選択した音声のパケットをクリップ末尾まで調べ、メモリ使用量を抑えながら開始・終了時刻を確認します。全音声パケットの時刻が連続していることを確認できた場合だけ採用し、時刻の欠落・途中の隙間・重複・破損は引き続きエラーにします。映像の長さで音声の長さを代用しません。

Save FLACは、選択曲を現在のレンダリング方式で左右2chに保存します。既定は16-bit / 44.1 kHz、この保存では24-bit / 48 kHzも選べます。ファイル名の[Speaker Stereo]、[Headphone Direct]、[Headphone Binaural]で用途を区別します。Speaker Stereoは、サブなしの左右スピーカーでも、外部アンプがサブに低域を分配する設備でも同じ2chファイルです。音の位置情報そのものをFLACへ保存する機能ではありません。

HRTF保存の頭部方向は書き出し開始時に固定します。トラッカーの動きを録音しません。メイン画面のFLAC保存欄にある **「ADM・ヘッドフォン書き出しの設定をJSONにも保存」** は初期状態でオフです。オンにした場合だけ、各FLACの隣の`.render.json`にSOFAのハッシュ、姿勢、ミキサー、ゲイン、LFE、反射などを記録します。同じ条件で再現するための補助情報であり、FLACの再生や埋め込みの曲名・アーティスト名には不要です。オフの場合は、この記録用の追加ラウドネス測定も省略します。既存のJSONは削除しません。曲別書き出しでは各曲でDSPを初期化します。別ファイル間でも畳み込み履歴を引き継ぐ連続アルバム保存は未対応です。

ADMの準備・再生・曲別保存では、表示時刻から戻す際に元のサンプル単位の曲境界とPCM終端を復元します。最終曲が丸め誤差で末尾を1サンプル超えることを防ぎ、隣り合う曲の欠落・重複も防ぎます。実際に元音源の範囲外を指定した場合はエラーにします。

元チャンネルを保つ通常のマルチチャンネルFLAC保存は、ADMを解除して元の音源側で選択します。自動正規化は行いません。

## うまく動かないとき

- 「音声データを最後まで読み取れませんでした」と出る場合：ディスクやISOが引き続きマウントされ、ドライブの接続が保たれていることを確認して再実行してください。ADM準備・随時デコードともFFmpegの読み取りエラーが出た時点で停止し、途中までのデコードを完成した保存ファイルとして扱いません。切り出し処理のエラーと入力条件はローカルログに記録します。DiscChannelLabにはISOの自動アンマウント処理はありません。
- ボタンが押せない：対応するADMまたはTrueHD Atmosが選択中のタイトルで検出されているか確認してください。
- 音が大きい／小さい：HRTFのトリム、共通ヘッドルーム、LFE、マスター、他のOS音響処理を確認します。ヘッドホンの既定ヘッドルームは−12 dBです。直接出力するStereo presentationではHRTFとヘッドホンのヘッドルームを通しません。
- シークが遅い：Preparedより先の初回シークは準備待ちになります。キャンセル・音源変更で中止できます。
- 途切れる：Pure HRTFに戻し、追加反射や他の高負荷処理を切って確認します。音源を黙って間引く処理は行いません。
- 音源やツールのエラー：通常のチャンネル音声へ戻せます。保護解除や非対応メタデータの推測補完は行いません。
