# Space sketch — 3D音声ビジュアライザー

[English](visualizer.md) · [DiscChannelLabへ戻る](../README.ja.md)

Space sketchは、DiscChannelLabの再生に連携する実験的な別窓ビューアーです。各チャンネルの周波数帯ごとのエネルギーを色付きの粒子に変え、「音が空間を満たす」様子を眺めながら、多チャンネル音声の中身を体感できます。

## 全体の表示

![多チャンネルの粒子を全体から見た画面](screenshots/visualizer.png)

低音は赤～橙で低い位置、高音は青～紫で高い位置に表示します。LFE以外は各スピーカーからリスナーの水平位置へ放射し、**Spread**で左右の最大角度を0～90°に調整します（初期値±20°、高い帯域はさらに狭くなる場合があります）。高さは対数周波数で固定し、粒子はリスナーを通り過ぎて徐々に消えます。

LFEは**リスナーの足元中央から水平360°全周**へ放射し、Spreadの影響を受けません。低音を表す演出であり、実際のサブウーファーの設置位置を示すものではありません。LFEのない音源にLFEを追加することもありません。

## リスナー視点

![リスナー位置から前方を眺める画面](screenshots/listener.png)

**Camera → Listener**で目の位置を固定して見回せます。**Bird’s-eye**は鳥瞰、**Top**は真上からの表示です。Overview／Front／Backも選択できます。ビューアーのUIは英語固定です。

| 操作 | 動作 |
| --- | --- |
| 空間をクリック後、↑↓を押し続ける | 水平を通って真上・真下まで上下に向きを変える。外側の視点では空間の上側・下側へ回り込む |
| ←→を押し続ける | 360°を越えて連続回転 |
| 左ドラッグ | 外側では回転、Listenerでは見回す |
| 右ドラッグ／ホイール | 外側では移動／ズーム。Listenerでは位置を固定 |
| Reset camera | Overviewへ戻る |
| Hide UI／Show UI、またはH | 情報・操作パネル、凡例、チャンネル名を隠す／戻す |
| Save settings、またはCtrl+S | 現在の表示設定と視点を保存 |
| Load saved | 保存した設定に戻す |

スライダーや選択欄にフォーカスがある間、矢印キーはその項目の操作を優先します。空間をクリックしてから視点を操作してください。一時停止中も見回せます。

## 本体との連携

1. リポジトリ直下で `./build.ps1` を実行します。`artifacts/public-win-x64`を、`SpaceSketch`サブフォルダーごと保持してください。
2. `DiscChannelLab.exe`で対応音源を選び、**Open Mixer**の隣の**3D Viewer**を押します。
3. 本体で再生すると、別窓の表示が再生・シークに追従します。再生操作と試聴音量は本体で操作します。

ビューアーは本体がデコードした音声を受け取ります。ディスクの読み込み、WAV／FLACを直接開く機能、音声書き出し、受信音声の二重再生は行いません。**5.1 demo**は音源不要の40秒の合成デモです。本体から起動した場合は**Link to DiscChannelLab**で連携に戻れます。デモのVolumeはデモだけに効きます。

別の場所にビルドしたビューアーは、選択画面で`DiscChannelLab.Visualizer.exe`を指定できます。3D Viewerボタンがない古い本体には連携機能がありません。

### 動作条件

- Windows x64、WebGLが使えるMicrosoft Edge。
- ビルドには.NET 10 SDK。公開用ビルドの実行には、x64の**.NET 10 Desktop Runtime**と**ASP.NET Core Runtime 10**が必要です。別のPCへ持ち出す場合は両方の導入を確認してください。
- 本体のディスク再生には利用者が用意したFFmpegを使います。ビューアー自体にはFFmpegや追加のコーデックは不要です。

## ミキサーの反映範囲

**Signal**で解析対象を選びます。

| 表示 | 内容 |
| --- | --- |
| Input channels | 管理されたミキサーに入る前の音声。Mute／Solo／Masterの影響を受けません。 |
| Post-mix channels（初期値） | 各チャンネルの左右寄与を合成したレベル。実際に使用中のミックスとMaster、フェーダー、Mute／Soloを反映します。 |
| Final stereo output | プレーヤーへ渡すクリップ処理後の2ch PCM。パン、足し合わせ、極性による相殺、音量を含みます。 |

Postは `sample × sqrt(leftWeight² + rightWeight²) × masterGain` です。チャンネルごとの寄与であり、個々の実スピーカーの信号を再構成したものではありません。等電力パンでは左右配分が変わっても合成エネルギーは変わらない場合があり、極性の符号だけでも個別チャンネルのエネルギーは変わりません。その違いや相殺は**Final stereo output**で確認してください。Input／Postでは元のチャンネル位置に表示します。

対応する多チャンネル再生経路では元のチャンネルを保持します。本体側ですでに2ch化している経路ではFL／FRを受信し、元のチャンネルは復元できません。変更したミキサー設定を反映するには、本体でミキサーを再生に適用してください。標準ミックスのLFEは初期状態で無音ですが、**Input channels**なら収録されたLFEを見られます。

両モードともスピーカーから放射した粒子が流れ続けます。過去の粒子の余韻は音声が残っていることを意味しません。ミキサー変更時は先読みを更新し、リスナー同期の古い粒子をクリアします。合成デモは本体のミキサーとは独立しています。

## 表示調整・設定保存

**Sync at** で同期の基準を選べます。

- **Listener (sound)**：標準。Speakers と同じくスピーカー位置から粒子を放射します。実際にデコードした先の音声を使い、「再生時刻＋粒子の移動時間」のスペクトルを参照して早めに放射します。周波数・速度・左右の角度を考慮し、リスナーに水平面上で最も近づく時刻を、その音の再生時刻にほぼ合わせます。中央に固定する粒子はありません。LFEは元から足元が放射位置なので先行時間は不要です。
- **Speakers (emission)**：従来の方式。音に合わせてスピーカー位置から粒子を放射します。リスナーへの到達には周波数と表示速度に応じた時間がかかります。

**Particle speed** は従来の速度を1倍として **0.5～4倍**、初期値は **2倍** です。音声の再生速度は変わりません。リスナー同期では速度に応じて放射を早める時間を計算し直します。両設定とも保存対象です。古い設定ファイルではリスナー同期・2倍を初期値にします。同期基準・速度・拡散角を変えたときはリスナー同期の古い粒子をクリアし、音声再生は続きます。

先読みは約8.2秒を上限とし、既存のデコーダーから先のPCMを取得します。実際の音は従来どおり出力直前にミックスし、可視化のバッファ待ちで再生を遅らせません。**本体とビューアーの両方を更新・再起動**してください。再生開始・シーク・曲や区間の切り替え・ミキサー変更の直後は、粒子が中央に届くまでの準備時間が必要です。先読みがない部分を推測したり、中央に粒子を補充したりはしません。先読み時のミキサー設定を使用するため、将来の操作は予測できず、実際の短い音量変化の平滑化とは差が出る場合があります。音声機器の実測遅延の補正ではありません。

両モードに、XYZ各軸でスピーカー距離の最大約**2％**（今の3.5m配置で約7cm）の滑らかな揺らぎを加えています。停止中は揺らぎも止まり、放射時はゼロになります。リスナー同期では中央でも各軸最大約1.8cmの滑らかな微振動が残ります。基準の軌道と放射時刻は変わりません。周波数による基準の高さを保ち、LFEは床付近に留まります。低音ほど寿命を長くし、**リスナー通過後**は高音ほど距離による減衰を強めています。実測した残響や空気吸収の再現ではなく、見た目の演出です。

**リスナー位置の強調：Listener (sound) のときだけ**、中央を通過する粒子を最大 **20％大きく**し、不透明度を最大 **50％増やして**明るく見せます。周波数の色は保ちます。水平方向の半径25cm以内で最も強調し、90cmまで滑らかに通常の表示へ戻します。周波数による高さにかかわらず同様に適用します。流れている粒子そのものへの効果で、中央に固定する粒子は追加しません。大きさ・透明度の操作も引き続き有効です。Speakers モードの見え方は変わりません。

Spread、Particle size（0.3～3倍）、Transparency（0～100%）、Density、Persistenceを調整できます。拡散幅・大きさ・透明度は既存の粒子にもすぐ反映し、一時停止中も調整できます。Transparencyは100%で粒子を隠し、0%で標準の淡さです。床ガイド、ラベル、LFE波紋は個別に切り替えられます。

**Save settings／Ctrl+S**はEXE横の`ViewerSettings.json`へ保存します。対象はSignal、表示設定、デモ音量、視点の種類と実際の角度・距離・移動位置、UIの表示状態です。次回起動時に復元しますが、変更の常時自動保存ではありません。UI非表示で起動したい場合は、隠してからCtrl+Sで保存します。ディスク情報やミキサープリセットとは独立しており、デモの自動再生も行いません。書き込み可能なフォルダーで使用してください。

`AudioVisualizationSettings.json`は別の解析設定ファイルです。編集後はビューアーを再起動してください。設定の読み込みに失敗しても現在の表示を維持し、保存失敗時も以前の保存ファイルを保持します。

## 表現の意味と限界

本機能はチャンネルの周波数特性を楽しむ可視化であり、**精密な音場シミュレーターや音圧の測定器ではありません**。粒子の色、高さ、速度、寿命、大きさ、広がり、床の波紋や残り方は演出です。収録された音源位置、実スピーカーの指向特性、反射、空間での位相干渉を再構成しません。LFEは床面、その他は周波数の高さで表示し、実際のスピーカーの標高は表しません。

初期解析は48kHz、Hann窓2048点、Hop512、対数16帯域（境界17個）、Attack45ms／Release300msです。低い帯域の分離はFFT分解能による制約があります。粒子上限は24,000個です。本体の再生時計に追従しますが、音声デバイスの実測遅延は補正しません。動作速度や聴感上の同期はPCと音声出力環境で変わります。

## ローカルデータと開発確認

同じWindowsユーザーに限定した一方向の名前付きパイプで連携します。画面は`127.0.0.1`内のサーバーで表示し、APIには起動ごとのトークンを使います。音声をアップロードしません。ブラウザープロファイル、接続トークン、ログは`SpaceSketch/cache`に保存します。これらと個人設定、音声試料、ビルド成果物、外部ツールはGit管理から除外します。ウィンドウを閉じると内部サーバーは約75秒後に終了します。

[連携プロトコル](visualizer-protocol.txt)に信号、配置、同期、キューの仕様を記載しています。開発用テストのコマンドは[英語版](visualizer.md#local-data-and-development-checks)を参照してください。

フロントエンドのテストはブラウザーと音声APIの模擬環境で実施し、GPUの実表示や聴感上の遅延は測定しません。掲載画像は利用者による実動作のスクリーンショットです。公開内容はソースの試用版で、バイナリーリリースやZIPは提供しません。
