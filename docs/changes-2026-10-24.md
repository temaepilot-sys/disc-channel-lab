# 2026-10-24 — Spatial Lab integration

## English

The approved Spatial Lab build is now part of the main DiscChannelLab source and application. Player identity is `DiscChannelLab.exe`, using `%LOCALAPPDATA%/DiscChannelLab`. Startup remains 2ch Stereo, with English and dark mode as the fresh-install defaults. Existing Particles/Spark/Veil modes and their controls are retained.

Added: multiple SOFA registration and native validation; visible A/B preparation and audition with level matching; shared real-time/offline binaural rendering; optional first-order room reflections; explicit measured BRIR routing and partitioned convolution; ADM BWF/BW64 Objects/DirectSpeakers input and inspection; opt-in progressive TrueHD object playback, seeking and full-title ADM archival through external truehdd 0.6.2.

Source presentation selection is available at the top of the comparison tab as well as in the main source panel. **Use 5.1 for HRIR / BRIR** provides an inline recovery from an incompatible Objects/stereo selection. Changing source mode invalidates cached A/B audio.

The approved trial profile is imported once. Newer settings and edits are copied with backups of replaced formal files; newer formal edits win. Internal JSON profile references are rebased to the formal profile. External response files remain at their actual locations. Original trial data, audio caches and prior application builds are retained separately. Caches and executable tools are not migrated.

Personal and public builds use the same application and DSP source. The personal folder can contain locally supplied external tools and presets. Public output excludes FFmpeg, truehdd, sacd_extract, personal presets, recordings and SOFA datasets; third-party software notices are retained.

Limitations: fixed-pose measured BRIR, documented ADM subset, no JOC object decoding, no HOA or general advanced ADM rendering, no codec certification and no copy-protection removal. Per-track exports reset DSP history. Numerical and UI verification does not replace personalized listening evaluation. See the linked guides for exact supported data and source preparation behavior.

## Spatial Lab window stability / ウィンドウの安定性修正

Fixed a reproduced case in which closing Spatial Lab during preparation left the main player disabled until the worker finished. Each operation now owns its interaction lock; closing releases that window's locks immediately, and an old completion cannot unlock a newly opened window. Closing also stops the timer, detaches notifications before cleanup, and cancels pending comparison / HRTF / reflection work. A closed instance is discarded; a minimized instance is restored when reopened.

Track changes cancel stale work and coalesce scene refreshes onto the UI dispatcher, while control availability is updated immediately. The actual chaptered full-title ADM was checked through repeated track changes and 12 close/reopen cycles; the same checks ran with the original synthetic ADM. Existing A/B, presentation selection, BRIR UI, ADM scene and pause/resume tests also passed. These changes concern window coordination; the audio DSP and file formats are unchanged.

比較準備などの処理中に閉じるとメイン画面が操作不能のまま残る事象を再現し、修正しました。ウィンドウを閉じた時点で自身の操作制限を解除し、残った処理が開き直した画面に干渉しないようにしました。曲変更では古い比較・設定処理を中止し、表示更新をUIスレッドへまとめます。閉じた画面は再生成し、最小化中なら元の大きさへ戻します。

After the stability fix, **229 checks passed**, covering synthetic and full-title ADM window lifecycles, A/B comparison, presentation selection, BRIR controls, scene interaction, transport and both distribution folders. Compilation again completed with zero errors and zero warnings. All **4,526 managed methods** in the final personal and public player builds have identical IL. These are the post-fix results; the earlier 320-check table documents the preceding integration run. Human listening evaluation remains separate.
